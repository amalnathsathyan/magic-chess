# Research and design notes

Working notes from Magic Chess R&D: early specs, design explorations,
deployment notes and hackathon/grant material. They are kept for reference when
planning program or backend changes. **They are not maintained** and may not
match the current code. The current documentation is at
<https://amalnathsathyan.github.io/magic-chess/>.

| File | What it is |
| --- | --- |
| `spec.md` | Original project spec and locked architecture decisions (Aug 2026) |
| `architecture-2026-08.md` | First architecture write-up |
| `backend-design.md` | Off-chain FEN, DB schema, Helius webhook, Redis and crank-worker design |
| `folder-structure.md` | Folder structure plan for program, SDK, frontend and backend |
| `deployment-notes-2026-08.md` | Early deployment notes |
| `improvement-notes-2026-08-11.md` | Improvement backlog from Aug 11 |
| `prediction-market-audit-2026-08.md` | Early design and audit notes for the on-chain prediction market |
| `agent-findings/` | 18 AI-agent research reports from Aug 2026: chess logic and security audits, SDK, MagicBlock, Privy, backend, testing, tokenomics, deploy. Start with `00-OVERVIEW.md` |
| `archive/` | Earlier state reports, frontend research, hackathon and grant material, pitch worker |

Unimplemented design proposals (fee-split treasury, token strategy) are in the
docs site under **Proposals**.
